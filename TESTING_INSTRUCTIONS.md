# 🧪 Инструкция по тестированию проекта Behoof

## 🚀 Начальные условия

### 1. Запуск MongoDB
```bash
# Убедитесь, что MongoDB запущена
# Обычно запускается автоматически или через:
mongod
```

### 2. Запуск Backend
```bash
cd backend
npm install
# Создать .env файл:
# PORT=5000
# MONGODB_URI=mongodb://localhost:27017/behoof
# FRONTEND_URL=http://localhost:5173
npm run dev
```
Сервер запустится на `http://localhost:5000`

### 3. Запуск Frontend
```bash
cd frontend
npm install
npm run dev
```
Приложение запустится на `http://localhost:5173`

## 🐛 Распространённые проблемы и решения

### Проблема: "Cannot connect to MongoDB"
**Решение:** Убедитесь, что MongoDB запущена:
```bash
# Windows
net start MongoDB

# Или через MongoDB Compass / MongoDB Shell
```

### Проблема: "Port 5000 already in use"
**Решение:** Измените порт в `backend/.env`:
```
PORT=5001
```
И обновите `vite.config.ts` proxy:
```javascript
target: 'http://localhost:5001'
```

### Проблема: "Token expired"
**Решение:** Выйдите и войдите снова

### Проблема: "Images not loading"
**Решение:** Проверьте, что папка `backend/public/uploads` существует и есть права на запись
