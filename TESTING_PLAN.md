# ПЛАН ТЕСТИРОВАНИЯ ДИПЛОМНОГО ПРОЕКТА (Behoof)

## ТЕХНОЛОГИЧЕСКИЙ СТЕК
- **Frontend:** Vue 3 + TypeScript + Pinia + Vue Router + Vite
- **Backend:** Node.js + Express + MongoDB + JWT
- **Хранение:** MongoDB (модели: Product, Order, Category, Brand, User, Cart, Notification, Model)

---

## ЭТАП 2: АВТОРИЗАЦИЯ И РЕГИСТРАЦИЯ

### Тест 2.1: Регистрация нового пользователя
**Действие:** Перейти на `/auth/register`, заполнить форму (email, пароль, имя, фамилия), нажать "Зарегистрироваться"
**Ожидаемый результат:**
- Успешная регистрация
- Токен сохранён в localStorage
- Перенаправление на `/profile` или главную страницу
- В BDD: POST `/api/auth/register` → 201, возвращается token и user

### Тест 2.2: Регистрация первого пользователя (становится админом)
**Действие:** Зарегистрироваться первым в системе
**Ожидаемый результат:**
- Роль пользователя = `admin` (проверить в профиле)
- Доступ к `/admin` открыт

### Тест 2.3: Вход (Login)
**Действие:** Перейти на `/auth/login`, ввести email и пароль, нажать "Войти"
**Ожидаемый результат:**
- Успешный вход
- Токен обновлён в localStorage
- Перенаправление на `/profile` или главную
- В BDD: POST `/api/auth/login` → 200

### Тест 2.4: Вход с неверными данными
**Действие:** Ввести неверный email или пароль
**Ожидаемый результат:**
- Сообщение об ошибке "Неверный email или пароль"
- Страница не закрыта, форма не очищена

### Тест 2.5: Проверка защиты маршрутов
**Действие:** Попробовать перейти на `/profile`, `/cart`, `/favorites` без авторизации
**Ожидаемый результат:**
- Редирект на `/auth/login?redirect=/profile` (или другой маршрут)
- После входа — редирект обратно на запрошенный маршрут

### Тест 2.6: Защита админских маршрутов
**Действие:** Не-админ пытается зайти на `/admin`
**Ожидаемый результат:**
- Редирект на главную страницу `/`

### Тест 2.7: Выход из системы
**Действие:** Нажать кнопку "Выйти" в профиле
**Ожидаемый результат:**
- Токен удалён из localStorage
- Пользователь перенаправлен на главную
- Все protected-маршруты снова недоступны

## ЭТАП 5: СТРАНИЦА ТОВАРА

### Тест 5.1: Просмотр товара
**Действие:** Кликнуть по карточке товара → `/product/:id`
**Ожидаемый результат:**
- Отображается: название, цена, описание, характеристики, изображения, отзывы
- Галерея изображений переключается
- Цена берётся из последней записи priceHistory

### Тест 5.2: Добавление в корзину
**Действие:** Нажать "В корзину" (требуется авторизация)
**Ожидаемый результат:**
- Товар добавляется в корзину (POST `/api/cart/items`)
- Счётчик корзины обновляется
- Показывается уведомление об успехе

### Тест 5.3: Добавление в избранное
**Действие:** Нажать сердечко "В избранное"
**Ожидаемый результат:**
- Товар добавляется в список избранного (lokalьно в favorites store)
- Иконка меняется на заполненную

### Тест 5.4: Добавление в сравнение
**Действие:** Нажать "Добавить к сравнению"
**Ожидаемый результат:**
- Товар добавляется в список сравнения (макс. 4 товара)
- При достижении лимита — сообщение "Достигнут лимит"
- Иконка меняется

### Тест 5.5: Написание отзыва
**Действие:** Написать текст отзыва, поставить оценки по характеристикам, отправить
**Ожидаемый результат:**
- POST `/api/products/:id/reviews` → 201
- Отзыв отображается в списке
- traitRatings товара пересчитываются
- Если отзыв уже есть — он обновляется (200 вместо 201)

### Тест 5.6: Ограничения отзыва
**Действие:** Отправить пустой отзыв / слишком длинный (>2000 символов) / оценку вне 1-5
**Ожидаемый результат:**
- Получение ошибки 400 с понятным сообщением

### Тест 5.7: Удаление своего отзыва
**Действие:** Удалить свой отзыв
**Ожидаемый результат:**
- DELETE `/api/products/:id/reviews/:reviewId` → 200
- Отзыв удалён, traitRatings пересчитаны
